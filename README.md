# 문 패트롤 🌙

추억의 오락실 문 패트롤(Irem, 1982)을 본뜬 혼자 하는 게임입니다. 서버 없이 `index.html` 만 열면 돌아갑니다.

- 조작(PC): **← →** 속도(느리게/빠르게), **스페이스/↑** 점프, **Z** 앞으로 쏘기, **X** 위로 쏘기, `P` 일시정지, `M` 소리.
- 조작(폰): 왼쪽 ◀ ▶ 로 속도, 파랑 점프, 빨강 앞 포, 노랑 위 포.
- 규칙은 `logic.js`(DOM 없음), 화면·소리·입력은 `game.js`. 시험: `node --test`.

## 규칙
- 버기가 달 표면을 달리고 땅이 왼쪽으로 흐릅니다. 속도는 느리게(65%) · 보통 · 빠르게(135%)로 바꿉니다.
- 땅 위: **구덩이**(점프로 넘기, 한가운데가 빠지면 죽음) · **작은 바위**(점프하거나 앞 포 한 방) · **큰 바위**(점프하거나 앞 포 세 방) · **지뢰**(점프만) · **탱크**(앞 포 한 방, 포탄은 점프로 피함).
- 하늘: UFO 떼(3~5대). 위 포로 맞히면 100점, 한 떼를 모두 잡으면 800점. UFO 가 떨어뜨린 폭탄은 땅에 **새 구덩이**를 만들고(위 포로 쏘면 부숨), 버기에 맞으면 죽습니다.
- 코스는 체크포인트 **A~Z** 26곳. 죽으면 마지막 체크포인트에서 다시 시작합니다. **E J O T Z** 에서는 기준 시간보다 빨리 오면 1초당 100점. Z 를 지나면 코스 클리어(1000점)이고 더 빠르고 빽빽한 코스(챔피언)로 이어집니다.
- 점수: 구덩이를 넘으면 10, 작은 바위 15, 큰 바위 20, 지뢰 15, 쏘아서 작은 바위 50 / 큰 바위 100 / 탱크 200, 폭탄 30. 버기가 10000점과 50000점에 한 대씩 늘어납니다.
- 3대로 시작합니다.

## 참고한 것과 확인하지 못한 값
- 공개 자료([Wikipedia](https://en.wikipedia.org/wiki/Moon_Patrol), [arcade-history](https://www.arcade-history.com/game/50713/), [StrategyWiki](https://strategywiki.org/wiki/Moon_Patrol/Walkthrough) 요약)에서 확인: 코스 A~Z 체크포인트(큰 체크포인트 E J O T Z 에서 시간 보너스), 구덩이·바위·지뢰·탱크·UFO 와 폭탄이 만드는 구덩이, 앞/위 두 방향 포, 한 떼를 모두 잡으면 800점 보너스, 기준 시간보다 빠르면 1초당 100점(이식판 설명), 챔피언 코스로 이어짐.
- 제가 정한 값(자료가 없거나 판마다 달라 확정하지 못함): 모든 점수(800과 1000을 뺀 나머지)·버기 목숨 3·추가 목숨 기준·속도 3단계·점프 높이/시간·장애물 크기·구간 길이·장애물 배치(코스 생성기)·UFO 움직임과 폭탄 확률·기준 시간(32초)·탱크 포탄 속도. 원작의 코스 배치를 옮긴 것이 아닙니다. 원작에 있는 지상의 적 자동차(추격)와 보스급 장애물은 넣지 않았습니다.
- 그림·소리는 직접 그린/합성한 것입니다.
